# 🚚 トラック積載シミュレーター（単一 HTML 版）

`index.html` 1 ファイルだけで動くトラック積載シミュレーターです。インストールもビルドも不要で、ブラウザで開けばそのまま使えます。3D 表示には [three.js r128](https://threejs.org/)（cdnjs から読み込み）を使っています。

## 使い方

`index.html` をダブルクリックして Chrome / Edge / Safari で開きます。初回だけ three.js を読み込むためにネット接続が必要です。

1. **① 荷姿・積付**：パレット規格を選び、「仕入先から追加」で仕入先を選択して箱数（または部品数）を入力 →「積付計算」
2. **② トラック**：「トラックへ送る」で仮置き場に並んだパレットを、「自動積載」またはマウスのドラッグで荷台に積みます
3. **③ 仕入先**：仕入先ごとの部品・荷姿（容器・収容数・単重など）を登録します。CSV で一括登録もできます
4. **④ 車種**：車種一覧。行をクリックすると、その車種に切り替わります

## 機能

| 区分 | 内容 |
|---|---|
| 仕入先マスタ | 仕入先コード・仕入先名・所在地・備考。部品ごとに品番・品名・容器・外寸・収容数（SNP）・単重・風袋・段積み上限・回転可・天地無用・上積み可を登録。1 箱の重量は「単重 × 収容数 + 風袋」で自動計算 |
| TP 箱 | TP111 / TP331 / TP332 / TP341 / TP342 / TP34系（H149・H241・H288）/ TP361 / TP362。容器を選ぶと外寸が自動で入ります |
| 積付 | 段積みパターン（2 ブロック・風車型）と Extreme-Point 法（混載）。支持率・上積み禁止・段積み上限・パレット最大重量／高さをチェック。「仕入先ごとにパレットを分ける」も選べます |
| 3D 積載 | ドラッグで積載・荷降ろし、他のパレットの上に置くと自動で段積み、R キーで回転。緑の枠は配置可能、赤の枠は配置不可（理由も表示） |
| 車種 | 軽トラ、2t、3t、4t（標準・ワイド・低床）、増トン、10t（大型・低床4軸・平ボディ）、20ft / 40ft コンテナ。寸法を変えてカスタム車種として保存できます |
| 集計 | 積載率、床面積率、容積率、重心、軸重配分（参考）、過積載・干渉・偏荷重の警告、積込順リスト |
| 入出力 | マスタ CSV の入出力（Shift_JIS / UTF-8 に対応）、積載計画 JSON、積込リスト CSV、PNG 画像。データはブラウザ（localStorage）に自動保存されます |

## 仕入先マスタ CSV の列

`仕入先コード, 仕入先名, 所在地, 備考, 品番, 品名, 容器, 長さmm, 幅mm, 高さmm, 収容数, 単重kg, 風袋kg, 段積み上限, 回転可, 天地無用, 上積み可`

- 必須の列は「仕入先コード」と「品番」だけです。
- 容器が TP 箱なら、寸法の列は空欄でかまいません。
- 回転可・天地無用・上積み可は `1/0`、`○/×`、`可` などで指定します。
- 「CSV テンプレート」ボタンでひな形をダウンロードできます。

## 注意

- 同梱の仕入先（S1001〜S1005）は **架空のサンプル** です。実際の仕入先・品番・荷姿に置き換えてください。
- TP 箱の外寸は公開されている規格表の代表値です。メーカーによって数 mm の差があります。風袋重量は実測値を入力してください。
- 車種の寸法と最大積載量は一般的なボディの代表値です。実際の値は車検証や架装仕様で確認してください。
- 軸重配分は貨物の重量だけを前後軸に振り分けた参考値で、車両の自重は含みません。
